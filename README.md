# Daily Grind Tracker

I want to build a fitness webapp that tracks my fitness progress and keeps my scheduele. I want to be able to enter an exercise that is saved to a list, and add a category for example pull. push, mixed. I also want to add the muscle group that it targets like chest, beck, legs. Make sure I can set a standard reps, sets and weights as well by each.
Then I want to be easily able to select from the list, add from the list to quickly make a program for the day.
When selecting I want to see which I have already selected before in the previous session up to 3 sessions ago.
During the session, I want to see a list of the exercises in orders and be able to change reps, sets and weights live to change on the fly.
Very important, I want to be able to tap the exercise so that I can count the sets. When I tap, I want a timer to start. I can predefined the break timer in seconds. This has an alarm that let me know when the break is over and I need to start the next exercise.






## Development

```sh
git clone <this-repository-url>
cd <repository-name>

```
